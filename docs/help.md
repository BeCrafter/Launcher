## 1. 五个页面各管什么

| 页面 | 它管的东西 | 系统里对应的东西 |
|---|---|---|
| **Agent 管理** | 常驻/后台任务：登录时自动启动的服务、守护进程 | `launchd`（plist 文件 + `launchctl`） |
| **定时任务** | 按时间表执行的任务（每天 3 点跑一次备份那种） | `crontab`（用户级）/ `/etc/crontab`（系统级） |
| **端口服务** | 当前谁在监听哪个端口：谁占着 3000、能不能关掉 | `lsof -iTCP -sTCP:LISTEN` |
| **随心手记** | 给上面三件事写 Markdown 笔记，并**关联到具体的服务** | 普通 `.md` 文件（你自己的目录） |
| **AI 助手** | 用自然语言问上面三件事，或让它动手改（需授权） | 应用自己的工具层（不读模拟数据） |

左下角 **设置** 是应用自己的偏好（主题、语言、超时、权限），最后一项「关于」里有版本号与更新检查。

## 2. 三个最常用任务（照着做）

### 2.1 让一个脚本开机自启

1. 打开 **Agent 管理** → 顶栏 **新建任务** → 选作用域
   - **用户级**（`~/Library/LaunchAgents`）：只对你生效，**不需要管理员授权** ← 日常用这个
   - **全局**（`/Library/LaunchAgents`）/ **Daemon**（`/Library/LaunchDaemons`）：对所有用户生效，保存时要授权
2. 抽屉 **编辑** 页填：
   - **标签（Label）**：唯一标识，习惯上用反写域名（如 `com.me.backup`），**建好后别随便改**（它就是身份）
   - **程序**：要跑的可执行文件**绝对路径**（`/usr/local/bin/myscript.sh`）；脚本记得 `chmod +x`
   - **参数**：每个参数一行（**不要**写成一整行字符串）
   - **环境变量**：如果你的脚本内部还会调用 `node` / `go` / `python3` 等外部命令，**必须**在环境变量里显式设置 `PATH` —— launchd **不读** `~/.zshrc` 等 shell 配置，默认 PATH 只有 `/usr/bin:/bin:/usr/sbin:/sbin`，找不到命令任务就会静默失败（终端里能跑、载入后不跑，多半就是这个原因）
3. 展开 **生命周期** 卡 → 打开 **允许登录时加载**（= 写入 `RunAtLoad` 或 `KeepAlive` 策略）
4. 保存 → 回到列表，卡片上点 **启动**

> 想「一直活着、死了自动拉起」就选 KeepAlive 策略；只想「登录时跑一次」就留 RunAtLoad。

### 2.2 每天定时跑一条命令

1. 打开 **定时任务** → 顶栏 **新建任务**
2. 选预设（每天 / 每小时 / 每周…）或直接填五段表达式，输入框下方会实时翻译成人话，并给出**下次执行时间**
3. 命令写**绝对路径**（`cron` 的 `PATH` 很精简，`node foo.js` 常常找不到 node）
4. 要留日志就打开 **记录日志** —— 应用会把输出收敛到固定目录（见 [§12](#12-数据与文件在哪)）
5. **系统级**任务（写 `/etc/crontab`）保存时需要授权；该文件不存在时系统级不可选（macOS 保护，应用不会替你创建）

### 2.3 找到并结束占用某端口的进程

1. 打开 **端口服务**（停留时每 3 秒自动刷新）
2. 顶栏搜索框输入端口号，或直接找分组卡片
3. 卡片右侧：**↗** 在浏览器打开 `http://host:port`；**复制** 复制完整 URL；**重启** 终止后按原命令行拉起；**停止** 结束进程
4. 结束**他人**的进程（root、其他用户）会先弹系统授权框 —— 见 [§10](#10-权限与安全)

## 3. Agent 管理（launchd）

### 状态是什么意思

| 卡片状态 | 含义 |
|---|---|
| **运行中** | 已载入 + 有进程在跑（旁边显示 PID、运行时长、CPU / 内存） |
| **待运行** | 已载入但当前没有进程：等触发条件（登录、时间间隔、看门狗） |
| **已停止** | 没载入（或已载入但被停用） |
| **未保存草稿** | 新建了还没写盘 —— 此时所有操作按钮都不可用 |

另有一个只读橙色标记 **已停用**：那是 `launchctl` 的「默认不加载」标志位（跨重启持久），与「本次有没有载入」是两件事。

### 四个动作到底做了什么

应用的界面只暴露**意图**，`enable → bootstrap → kickstart` 的顺序由它自己处理，所以不会出现「因为顺序而置灰」的按钮：

| 按钮 | 实际动作 |
|---|---|
| **启动** | 确保已启用 → 载入（bootstrap）→ 需要时立即执行一次 |
| **停止** | 移出 launchd（bootout）—— **只停本次**，不改变「开机自启」 |
| **重启** | 运行中走 `kickstart -k`；未载入则走启动序列 |
| **允许登录时加载** | 改的是**标志位**（enable / disable），**不动**当前运行状态 |

两点容易误解：

- **停止 ≠ 卸载/删除**：卡片还在、plist 还在，只是不在 launchd 里跑了。要删文件用抽屉底部的**删除**。
- **「允许登录时加载」是跨重启的**：关掉它不会立刻停掉正在跑的进程；反之打开它也不会立刻拉起 —— 那是「启动」的事。
- 在**已停用**的任务上点启动时，应用会问一句「要不要连自启一起开」——因为 launchd 的 `disable` 会**阻塞**载入，这是系统规则，不是应用的限制。

### 为什么有些文件只能改 XML

表单只覆盖最常用的一批键（19 个）。遇到下面两类，保存按钮会禁用并逐条说明原因，请切到 **XML** 标签页改：

- **表单拥有这个键、却表达不了当前写法**：例如同时写了 `Program` 和 `ProgramArguments`、`KeepAlive` 里有表单不认识的子键、环境变量不是字符串
- **结构无法增量改写**：文件整体不是可逐节点打补丁的形态（应用会明确告诉你）

其余**表单不认识的键**（例如 `MachServices`、`Umask`）不会锁表单：保存时它们**原样保留**，页面顶部会提示一句「保存时原文保留」。

> 应用保存 plist 走的是**节点级补丁**：只改你动过的地方，注释与排版尽量不动。

### 其他

- **PATH 是必须显式设置的**：launchd **不加载** `~/.zshrc` / `~/.zprofile` 等 shell 配置，默认 PATH 只有 `/usr/bin:/bin:/usr/sbin:/sbin`。程序路径用绝对路径；脚本内部还会调用 `node` / `go` 等外部命令时，**必须**在 plist 的环境变量（`EnvironmentVariables.PATH`）里写入你登录 shell 的 PATH（`echo $PATH` 可查看）。这是必须项，不是可选优化 —— 不设的话任务会因 `command not found` 静默失败
- **Homebrew 服务**：由 `brew services` 管的条目会带 Homebrew 标签，启停走 brew 自己的路由（否则两边会打架）
- **「已加载但 plist 已不存在」**：launchd 里还挂着、文件却没了（多半是手动删过）。卡片上会出现橙色横幅，点 **移除** 把它从 launchd 里清掉
- **XML 标签页**：可直接编辑原文，保存前会做语法校验（等同 `plutil -lint`）
- **日志标签页**：两个来源可切 —— **日志文件**（读 `StandardOutPath` / `StandardErrorPath` 指向的文件尾部）与**系统日志**（`log show`，可按级别过滤）
- **外部改动会自己同步**：在 Finder 或别的工具里增删 plist，列表会自动刷新（可在设置里关掉 FSEvents 监听）

## 4. 定时任务（crontab）

- **表达式**：五段（分 时 日 月 周）。输入框下方实时给出人话描述与**下次执行时间**；`dom`（日）与 `dow`（周）同时限定时按 cron 的 OR 规则计算
- **内置预设**：每天 / 每小时 / 每周 / 每月 / 开机后等常用组合，点一下就填好
- **停用任务**：不是删掉这一行，而是在行首加一个标记（应用自己认这个标记），随时可再启用
- **日志**：打开「记录日志」后，应用会重写那一行，把输出重定向到固定目录并按**小时分段**（这样过期文件才会被真正清理）。日志抽屉左边是分段文件列表、右边是正文，可逐段删除或一键清理过期段

### 为什么我配了日志路径，却一直没有日志？

最常见的原因是命令里有**未转义的 `%`**：`crontab` 会把 `%` 当成换行，**从那里截断命令**（后面的内容变成命令的 stdin），任务于是静默失败、日志文件根本不会生成。
典型受害者：`date +%Y-%m-%d`、`strftime('%H')`。

应用的检测与修复：卡片上出现黄色 **需修复转义** 告警 → 点一下，它会把该行的 `%` 转义成 `\%`（只动这些字符，其余原样），之后任务就能正常跑并产生日志。

### 其他常见「没执行」

| 症状 | 常见原因 |
|---|---|
| 完全没跑 | 命令不是绝对路径；cron 的 `PATH` 很短，`node`/`python3` 往往找不到 |
| 手动跑得通、cron 跑不通 | 环境变量不同（`HOME`、`PATH` 差异）；建议在命令里显式 `cd` 与用绝对路径 |
| 只有日志空 | 命令输出到了 stderr 但没打开「记录日志」；或用了上面说的 `%` 截断 |
| 系统级任务改不了 | `/etc/crontab` 不存在（macOS 保护禁止新建）；用户级不受此限 |

## 5. 端口服务

- **分组怎么来的**：拿监听进程的名字/命令行与 `brew services` 清单、常见运行时（node）、Docker 容器交叉判定，落到 **Homebrew / Node.js / 进程 / Docker** 四组；鼠标悬停在类型标签上会显示判定依据
- **列表里那一大堆系统进程是正常的**：macOS 上每个 GUI 应用几乎都会开几个本地 IPC 端口（`ControlCenter`、`FinderSync`…）。这些端口只在 `127.0.0.1` 或 `*` 上，**不要随便关** —— 关了对应的应用会出问题
- **停止 vs 重启**：停止是 `SIGTERM`，5 秒内没退再 `SIGKILL`；重启会**按记录到的命令行**重新拉起 —— 如果原进程属于其他用户，重启后的身份会变成你（应用会先说明这一点）
- **改显示名 / Host / 路径**：双击卡片名字就地改名；点 **⚙** 可以设置别名、Host 与路径，之后 **↗ 打开** 与 **复制** 用的都是 `http://host:port/path` 这个完整地址。这些覆写按「端口 + 程序名」记账，**进程重启后依然保留**
- **「扫描失败」横幅**：说明这一轮没能读到系统状态（`lsof` / `ps` 出问题），此时列表里是**上次成功的结果**，不是当前真相。恢复后会自动刷新
- **Docker 组**：Docker 没装或没在跑时，该组会给出原因（未安装 CLI / daemon 未运行 / 响应超时），而不是静默消失

## 6. 随心手记

一笔记一个 Markdown 文件，默认放在 `~/.config/launcher/notes/`（**设置 → 随心手记**里可以改，比如直接指到你已有的 Obsidian 库）。
文件就是普通的 `.md` 加一段 frontmatter，用 Obsidian、iCloud、git 直接改都行 —— 应用会发现并重新载入。

### 三栏各是什么

左边是列表（搜索框在它顶部，**搜的是正文**，不只是标题）；中间写，右边实时预览。
标题按整条路径显示：`目录/` 与 `.md` 是灰色的（由文件位置决定，不可编辑），中间那段才是可以改的名字 ——
改完离开输入框，文件名会跟着变。

顶上只有两行：标题行，和一行「视图切换 ｜ 关联与标签」。视图切换是三个图标按钮
（分栏 / 只编辑 / 只预览，悬停有说明），竖线右边才是关联服务与标签；内容多时这一行会自己折行。
标题行右端是这篇笔记的动作：**在 AI 中引用**（✨，见「把笔记引用给 AI」）、置顶、删除。
列表里只有名字，**排序固定按创建时间** —— 不是按「最近更新」：那个值会被自动保存刷新，
于是点一下笔记列表就重排一次。按创建时间排，顺序不会因为你点来点去而变。
标签不再单独铺一行（标签一多那行就没法看了），改成**在搜索框里联动**：输入的内容如果命中了某个标签，
带这个标签的笔记会**排到最前**，并在行尾标出 `#标签名` 说明它为什么在前面；
没有任何标签命中时，就是普通的内容搜索结果，顺序完全不变。

搜索时结果会**摊平**显示（不再按目录缩进）—— 命中的笔记常常散在各个目录里，摊平才好扫；
行尾的悬停提示里仍能看到它的完整路径。

### 目录

**文件夹就是磁盘上的真实目录**，笔记文件直接躺在里面，
所以在访达 / Obsidian 里看到的层级和这里完全一致。把鼠标移到某个文件夹上会出现四个小按钮：
在此新建笔记、在此新建子文件夹、重命名、删除（连同里面的笔记一起进废纸篓，可恢复）。
笔记页不显示顶栏 —— 操作都在左栏里，顶栏只剩一个面包屑，不如整条让给正文。

新建入口只有两处，各管一件事：
- **目录行上的按钮** → 建到**那个目录里**（笔记或子目录）
- **列表最底下的一对按钮「新建笔记 / 新建文件夹」** → 建在**根层**

也就是：要放进某个目录就从那一行建，要放在最外层就用底部那对。

**拖动**笔记或目录就能换位置：拖到某个目录上即移进去，拖到列表空白处即移回根层。
不能把目录拖进它自己里面（那会把整棵子树摘掉），应用会直接拒绝。

把鼠标移到任意一行上，右侧会出现 **置顶** 与 **删除** 两个按钮。删除同样进系统废纸篓。
置顶不会改动「更新时间」—— 否则取消置顶时那篇会突然跳到「最近更新」的最前面。

**置顶的笔记永远在列表最顶**，不随排序方式变化，也不会在目录树里重复出现 —— 它就在「置顶」那一栏里。
点「置顶」那一行可以把它折叠起来（状态会记住）。

把外部已有的目录（比如一整个 Obsidian 库）拷进笔记目录，或者在里面直接新建目录和 `.md`，
应用都会自动发现并刷新出来，不需要重启。

### 关联到某个服务

这是它和别的记事本最不一样的地方。点「关联服务」可以把笔记挂到：

- 一个 **Launch Agent**（按 Label）
- 一条 **定时任务**
- 一个 **端口服务**

挂上之后笔记顶部会显示「Launch Agent · com.foo.bar」这样的标签，**点一下直接跳到那个服务**。
反过来，Agent 卡片的「更多」菜单、端口服务的「配置」、定时任务的动作行里都有「相关笔记」，点进去就是按该服务筛选过的笔记列表。

**端口服务的关联不会因为进程重启而失效** —— 它记的是「端口 + 程序名」，不是 PID。
关联还能用但对象变过（作用域挪了、命令改了）时显示成琥珀色，旁边有个按钮可以把链接更新到当前对象；真的找不到了才显示「已失效」。

### 自动保存与冲突

编辑时底部有一条工具条：左边是常用的排版按钮（加粗 / 斜体 / 行内代码 / 链接 ｜ 标题 / 列表 / 任务 / 引用 ｜
代码块 / 图片 / **表格** / **网页嵌入** / **图表**），右边显示字数；笔记为空时那里改成一句提示。
`⌘B` / `⌘I` / `⌘K` 分别对应加粗、斜体、链接。
**切成「只预览」时整条会收起来** —— 排版按钮只对编辑有意义，而预览也就多出这一条的高度。

编辑区是**源码模式**：等宽字体，每一行严格等高。标题不会变大、代码块没有整块底色、引用没有竖条 ——
它只做两件事：**上色**（标记压暗，关键字 / 字符串 / 注释 / 链接着色，表格分隔符压暗、表头加粗、
任务项的 `[ ]` 着色、提示块标记按类型上色）和**字形**（加粗显示为粗体、斜体显示为斜体）。
想看成品的排版，看右边预览区。两边代码的配色是同一套，同一个 `const` 在两边是同一个颜色。

分栏时两个区域**联动滚动** —— 滚左边右边跟着走，滚右边左边跟着走，靠的是「这一块在源文里是第几行」而不是
按高度比例（两边的总高度几乎从不相等，按比例会越滚越偏）。元数据行上的 🔗 按钮可以关掉它。

打完字约 1 秒自动保存，不需要按保存键。**改标题也会自动改文件名** —— 离开标题框时，
文件名会跟着标题变（同名已存在时自动弹询问，让你选取消还是保留两者）。

三件值得知道的事：

- **在应用外改了同一篇笔记**：应用会重新载入并提示。如果那时你还有没保存的改动，会出一条横幅让你选「用磁盘版本」还是「保留我的版本」——**默认两边都不丢**。
- **应用不认识的 frontmatter 键**（比如 Obsidian 的 `aliases`、`cssclasses`）**会原样保留**，不会被重写。如果整段 frontmatter 形态看不懂（比如围栏没闭合），应用会整份当正文处理，只提示、不改写。

### 图表（Mermaid）

工具条最右边的按钮可以插入一张图。选类型（流程图 / 脑图 / 时序图 / 类图 / 状态图 / 关系图 / 饼图 / 甘特图）、
挑方向与主题，右边实时预览，满意了点「插入」。预览里把鼠标移到图上，右上角浮出「复制源码 / 放大 / 编辑」——
点铅笔可以**重新打开那张图的配置**，改完点「更新」，只替换那一块，正文其余部分一字不动。

图是标准的 Mermaid 代码块（```` ```mermaid ````），**配置写在源码里**（方向在 `flowchart LR` 那一行，
主题在 `%%{init: …}%%` 指令里），所以文件拿到 Obsidian、GitHub 上打开长得一样。
「跟随应用」是唯一的例外：它**不往文件里写任何东西**，而是渲染时按当前主题配色，深浅色切换图会跟着变。

语法写错了不会静默消失 —— 那块位置会直接显示 Mermaid 的报错和你的源码。

### 提示块（Callout）

写 `> [!NOTE]` 开头，那一整段引用就会在预览里变成一张带图标与配色的卡片：

```markdown
> [!WARNING] 改端口前先备份
> 直接改 plist 而没备份的话，出问题只能手抄回来。
```

五种类型：`NOTE`（蓝）· `TIP`（绿）· `IMPORTANT`（紫）· `WARNING`（琥珀）· `CAUTION`（红）。
标记后面可以跟自定义标题，不写就用类型名。卡片正文里照样能放列表、代码块、图片。

**在编辑器里敲 `> [` 会弹出这五种让你选**，回车插入整段骨架，接着打字就是正文。
提示块标记在编辑器里也按类型上色，扫一眼就知道这段是警告还是说明。

这套语法 **Obsidian 原生认、GitHub 也认** —— 文件拿到别处打开不会变成一堵纯文本。

### 表格

工具条上的表格按钮点开是一个 **8×8 的格子**，拖选到想要的大小再点一下，就插入一张带表头的空表。
表头写的是「列1 / 列2 …」占位名 —— 全空的表头在预览里是一片看不出边界的格子。

### 网页嵌入

工具条上的地球按钮：填地址、选高度，插入。地址可以是两种：

- **相对路径**（`assets/report.html`）→ 指向笔记目录里的本地网页，**不发任何网络请求**；
- **网址**（`https://…`）→ 预览会**直接去那个地址取页面**。

⚠ 第二种会让预览联网 —— 远程图片（见下一节）也走同一条路。这是应用里仅有的两处联网行为。
对话框里会根据地址类型变色提醒。嵌进来的页面跑在**沙箱 iframe** 里，碰不到应用本身。

写出来的源码是这样，也可以手写：

````markdown
```embed
https://example.com
height: 420
```
````

高度可省略（默认 380px）。站点如果禁止被嵌入，框里会是空白 —— 顶部那条地址栏右边有「在浏览器打开」。

### 文档、视频与音频

和图片一样的写法，按后缀自动换控件：

```markdown
![](assets/录屏.mp4)
![](assets/录音.m4a)
![](assets/手册.pdf)
```

- **视频 / 音频**：文档内直接播放，进度条能拖（附件协议支持分段请求，不用等整个文件下完）；
- **PDF**：文档内直接翻阅，用的是 Chromium 自带的阅读器；
- 支持的后缀：`mp4` `webm` `mov` `m4v` `ogv` / `mp3` `m4a` `wav` `ogg` `flac` `aac` / `pdf`。

文件都放在笔记目录的 `assets/` 里，和图片同一个地方。

### 图片

截图直接粘贴或拖进编辑区，会存到笔记目录的 `assets/` 里，正文自动插入 `![](assets/…)`。

**远程图片（`https://…`）会直接显示**。这意味着打开笔记时会向那个地址发一次请求 ——
和「网页嵌入」一样是联网行为（见上一节）。渲染出来的图带 `no-referrer`，不会把「你从哪篇笔记点过来的」一起送出去。
如果对方图床拦盗链或地址失效，那个位置会降级成一个可点的标签，而不是一个碎图标。

附件协议只服务笔记目录 `assets/` 下的白名单类型，路径穿越会被挡在协议处理器里。

### 任务清单

`- [ ]` / `- [x]` 在预览里可以直接勾，勾一下会改源文件，而且 **⌘Z 能撤销**。

### 让 AI 帮你记

AI 助手有 6 个笔记工具（列出 / 读取 / 看图 / 写入 / 关联 / 删除）。可以直接说「把刚才那个 8080 端口的排查过程记成一篇笔记」，
它会自己把服务关联挂上。写操作照旧要过授权卡；覆盖已有正文时卡片会标红。

### 把笔记引用给 AI

三种引用方式，引的都是**当时磁盘上的正文**：

- **在 AI 输入框里打 `@`** → 「笔记」分组里挑。行首的勾选框可以一次勾好几篇，底部按钮一次挂上；
  直接点行本体则是「引用这一篇，关掉弹层」。也可以按正文关键词搜（打两个字以上就会连正文一起搜）。
- **在笔记页点标题栏的 ✨ 按钮** → 自动切到 AI 页并把这篇挂上。
- **先在编辑区选中一段再点那个按钮** → 只引用**选中的那一段**，不引整篇。适合「就这段日志，帮我看看」。

挂上的引用会变成输入框上方的一枚 chip（笔记是绿色），点 ✕ 撤掉。一次最多引 10 项。

几点值得知道的：

- **引用不是复制粘贴**：正文只在发送时读一次拼进这一轮，**不写进对话记录**，也不显示在气泡里 ——
  之后你在笔记里改了内容，下一轮问的就是新版本。
- **正文会一直留在上下文里**：被引用的笔记在后续每一轮都会再发给模型（这样它才不会「忘了刚才那篇」）。
  代价是 token —— 引用大部头笔记前想一下值不值。单篇最多 64 KiB，一条消息里的引用总量最多 128 KiB，
  超了会在提示里明说是哪几篇没带上。
- **图片要单独看**：笔记里的截图不会自动塞给模型（那会把请求撑得很大）。正文里有图时它会知道，
  需要时会自己调 `read_note_image` 去看。看了的图**只在那一轮有效**，不写进对话记录 ——
  想让它再看一次，说一声就行（本地读文件，几乎不花钱）。
- **引用的笔记被删了/改名了**：模型会看到「已不存在」，而不是收到一段错的正文。
- 引用了不等于「读过了」：让 AI **改写**某篇笔记时，它仍会先 `read_note` 读一遍当前内容 ——
  这条纪律是为了避免它凭一段可能被截断的引用去覆盖你的原文。

## 7. 编辑器高级用法

这一章是**速查**：不试一下不会知道的写法都在这儿。想直接看效果，打开笔记目录里的
**随心手记示例**那篇（首次运行、目录为空时自动生成），照着改就行。

### 编辑区是源码，不是所见即所得

左边是**源码**，右边是**成品**。编辑区只做两件事：**上色**（标记压暗、语法着色）和
**字形**（加粗显示为粗体、斜体显示为斜体）。标题不会变大、代码块没有整块底色 ——
所以每一行严格等高，读起来就是一份可以改的源码。

这是刻意的：标题一旦开始变大、代码块一旦有底色，行高就不再统一，那读起来是「一份渲染过的
文档」而不是「我在改源码」。**排版是右边预览区的事。**

### 尺寸：写在方括号里，也能拖出来

图片、视频、音频、PDF 的尺寸写在 alt 里 —— 这是 Obsidian 的写法，拿到 Obsidian 原生认：

| 写法 | 含义 |
|---|---|
| `![封面\|300](assets/a.png)` | 宽度 300px |
| `![封面\|300x200](assets/a.png)` | 宽 300、高 200（会拉伸） |
| `![\|x400](assets/a.pdf)` | 只定高（PDF 的宽度总是铺满） |

**在预览里点一下媒体**，右下角会出现一个角柄，拖它就能改大小，松手自动把上面的语法改写掉。
图片/视频/音频拖的是宽度（高按比例），**PDF 与网页嵌入**拖的是高度（宽总是铺满）。
范围限制在 40–2400px。**四类媒体加上网页嵌入都能这样缩放**，不只是图片。

同一张图在正文里出现多次时可能定位不到唯一一张 —— 那时会明确提示「没有改动」，
而不是随便挑一张改掉。

### 表格可以就地改

预览里的表格**双击一个格子**就能改内容（回车提交、Esc 取消），改完自动重排对齐。
鼠标移到表格上，行首与表头会出现 `×`（删这行 / 删这列），表格下方有「加一行 / 加一列」。

改的是**源文**：重排只动空白，不动任何单元格内容。删到只剩一列时不允许再删 ——
一张没有列的表没有意义。

**格子里还能放块级内容**：一行源文里用 `<br>` 当行分隔符 —— 列表、代码块、流程图、嵌套表格、
图片 / 视频 / PDF 都能塞进去（写竖线要转义成 `\|`，不转义会被当成列分隔符）。
格子里的任务清单、表格、图表是**只读**的：它们全都来自同一行源文，按行回写会写坏整条表格行。
格子里的图 / 视频 / 图表会跟着格子缩放。

**列宽与行高**写在 ````table 围栏里（`cols=200,100,auto`、`rows=80,40`），也可以在预览里
**直接拖列边界 / 行边界**，松手把数字写回围栏。想要「左图右文」这类版式，在围栏里加一个
`layout` —— 它会把表格当网格用：不带边框，第一行也不再当表头。

想直接看效果，打开笔记目录里的 **随心手记示例** 那篇。

### 表格边框：全局默认 + 单表覆盖

GFM 的表格语法没有属性位，所以边框分两级：

- **全局**：设置 › 随心手记 › 表格样式 —— 边框粗细（无 / 细 / 中 / 粗）与颜色。
- **单表**：把表格包进一层 `table` 围栏，只覆盖写了的项：

````markdown
```table border=none
| 无边框 | 靠对齐也能读 |
|---|---|
| 甲 | 乙 |
```
````

认得的键只有两个：`border=none|thin|medium|thick`、`color=#8b5cf6`（或颜色名）。
写错的键会被忽略 —— 一个拼错的词不该把整张表变成错误提示。

代价是这层围栏在 Obsidian / GitHub 上会以代码块的样子露出来。所以它只用于**个别**表；
默认那套写在设置里，一篇笔记不写任何围栏也能有统一好看的表格。

### 代码块

围栏里写上语言名就有语法高亮。**鼠标移到代码块右上角**会出现语言角标与复制按钮，
复制的是**原始代码**，不带任何高亮标记 —— 拿出去能直接粘进终端。

认得 40 多种语言：`js` `ts` `jsx` `tsx` `json` `html` `css` `scss` `xml` **`plist`**
`markdown` `sh` `bash` `zsh` `py` `yaml` `toml` `ini` `sql` `go` `rust` `c` `c++` `java`
`kotlin` `swift` `ruby` `lua` `perl` `diff` `dockerfile` `nginx` `powershell` …
写不出来的语言当纯文本处理，不会乱染色。

### 提示块

`> [!类型]`，五种：`NOTE`（蓝）`TIP`（绿）`IMPORTANT`（紫）`WARNING`（琥珀）`CAUTION`（红）。
标记后面跟的文字就是自定义标题。**在编辑器里敲 `> [` 会弹出这五种让你选。**

**不带 `[!类型]` 的普通引用（`> ` 开头）同样按块渲染** —— 里面可以放列表、代码块、表格、嵌套引用。

这套语法 Obsidian 原生认、GitHub 也认 —— 文件拿到别处不会变成一堵纯文本。

### 网页嵌入

工具条上的地球按钮：填地址、选高度。相对路径（`assets/report.html`）指向笔记目录里的本地网页，
**不发网络请求**；网址（`https://…`）会让预览**直接去取那个页面**。

### 图表

工具条最右的按钮插入 Mermaid 图（流程图 / 脑图 / 时序图 / 类图 / 状态图 / 关系图 / 饼图 / 甘特图），
可以可视化配方向与主题。悬停已渲染的图，右上角能复制源码或重新编辑。
配置写回**标准 Mermaid 源码**，所以文件在 Obsidian / GitHub 上长得一样。

### 联动滚动

分栏时两边一起滚，靠的是「这一块在源文里是第几行」，不是按高度比例 —— 两边总高度几乎从不相等，
按比例会越滚越偏。元数据行上的 🔗 按钮可以关掉。

## 8. AI 助手

### 先配置

**设置 → AI 助手**：选协议（Anthropic / OpenAI 兼容）→ 填端点与 **API Key** → 选模型。填完可以点「测试连接」验证。

- Key 只存在**本机**、经系统钥匙串加密（明文不落磁盘），随「恢复默认」一并清除
- OpenAI 兼容协议适用于绝大多数第三方网关（DeepSeek、Qwen、自建 vLLM…），端点填到 `/v1` 为止

### 它能做什么

它调用的是应用自己的工具层（**读的是真实系统状态**，不是模拟数据），共 20 个工具：

- **只读 12 个**：列出/查询 Agent、定时任务、端口服务，读 plist 原文、读日志、看某任务的运行状态、读笔记（含笔记里的截图）…
- **需授权 8 个**：改 plist、写文件、执行写操作等 —— 每次执行前都会弹出**授权卡**，卡里写明**将要执行的命令**，你点「允许」才会跑

写工具是否**可见**由 **MCP 权限模式**决定（默认 `readOnly` 只暴露 12 个只读工具）；但**即使可见，执行仍要你逐次授权**。

内置技能（生成 LaunchAgent、诊断任务…）在**载入任务后会自动验证**：AI 载入 plist 后应用会再查一次运行状态与日志，把真实读数交给 AI 核对 —— 没跑起来或日志报错时它会继续诊断修复，而不是直接汇报「完成了」。

### 接外部 Agent（MCP）

「AI 助手 → 顶栏 **接入 MCP**」里有两种形态：

| 形态 | 说明 |
|---|---|
| **stdio** | 命令 `launcher-mcp`（应用内含的入口）。点一次 **安装到 PATH** 就能只用命令名挂载，例如 `claude mcp add launcher -- launcher-mcp`；不装也行，弹窗里始终给出可复制的完整路径命令 |
| **HTTP** | `http://127.0.0.1:7788/mcp`，应用运行时可用，无需额外进程 |

弹窗顶部会显示 PATH 链接的真实状态（已安装 / 未安装 / 悬空 / 指向另一个副本），不一致时点「修复指向」即可。

## 10. 权限与安全

**什么时候会弹系统授权框**（应用说明意图 → 系统原生框 → 你输入密码 → 应用才继续）：

- 读写**系统级**文件：`/Library/LaunchAgents`、`/Library/LaunchDaemons`、`/etc/crontab`
- 结束或重启**属于其他用户**（含 root）的进程

**应用不接触你的密码**：密码只进 macOS 的原生授权框（应用既不读也不存）。

**哪些操作会真的改系统**（都在你点下去之后才发生，且界面会提示）：

| 操作 | 改了什么 | 怎么回滚 |
|---|---|---|
| 新建 / 保存 Agent | 写入对应目录的 `.plist` | 抽屉底部**删除**（或直接从 Finder 删文件） |
| 启动 / 停止 / 重启 | 只动 launchd 的运行时状态 | 反向操作即可 |
| 允许登录时加载 | 改 `launchctl` 的标志位（跨重启） | 关掉开关 |
| 新建 / 修改定时任务 | 改写 `crontab`（或 `/etc/crontab`） | 应用内删除，或 `crontab -e` 手工改回 |
| 结束 / 重启端口进程 | 终止真实进程 | 重启会按原命令行拉起；部分进程只能重启其宿主应用 |
| AI 写操作 | 由授权卡逐次确认后才执行 | 同上 |

## 11. 常见问题

**Q：点了「启动」，状态几秒后才变？**
`launchctl` 的状态传播有约 2 秒延迟，重启（`kickstart -k`）还会被系统节流。应用会在这之后自动刷新一次，稍等即可。

**Q：任务显示「已停止」，但 `ps` 里还能看到进程？**
两种常见情况：① 那个进程是你自己在终端里起的，不受 launchd 管（应用停的是 launchd 里的那份）；② 任务配了 `KeepAlive`，杀掉会被立刻拉起 —— 要停就先把策略关掉或直接停用该任务。

**Q：我改了 plist（或在别处改了），为什么界面没变？**
列表会自动刷新；但**改动要生效需要重新载入** —— 在应用里保存时会自动重载「原本已载入的任务」，手工在 Finder 改的文件请在卡片上按一次 **重启**（或 **停止 → 启动**）。

**Q：删除任务会连带删掉日志吗？**
不会。删除只移除那一条任务；日志留在固定目录里，按「定时任务日志保留」设置自动清理。

**Q：端口服务的「停止」按了，进程又起来了？**
说明它由别的机制看着：`KeepAlive` 的 Agent、应用的自动重启、或 Docker 容器（容器用组内的 stop 按钮，别用 kill）。

**Q：为什么 Homebrew 的服务改不了 XML？**
它由 `brew services` 管理，直接改文件会和 brew 的记录打架。要改请用 `brew services stop`，编辑后再 `start`。

**Q：关掉这个应用，我的任务还会跑吗？**
会。任务归 `launchd` / `cron` 管，应用只是它们的界面。

**Q：我卸载应用，任务会没吗？**
不会。卸载不会删除你的 plist 与 crontab 条目（清理项见 [docs/install.md](https://github.com/BeCrafter/Launcher/blob/main/docs/install.md#卸载)）。

**Q：怎么把日志贴给别人排查？**
Agent：抽屉 → **日志** 标签页 → 导出（或直接给 `StandardOutPath` 的文件）。
定时任务：日志抽屉 → 选分段 → 复制正文。

**Q：AI 会不会把我的信息发出去？**
只有你发起的对话会走你配置的模型端点；应用本身无遥测、无账号系统。

## 13. 术语对照

| 系统里的词 | 说人话 |
|---|---|
| **launchd** | macOS 的后台任务总管（开机/登录后由它拉起并看管任务） |
| **LaunchAgent** | 属于某个用户的 launchd 任务（登录后运行，有图形会话权限） |
| **LaunchDaemon** | 系统级 launchd 任务（开机就运行，以 root 身份，无图形会话） |
| **plist** | launchd 任务的配置文件（XML 格式） |
| **Label** | 任务的唯一标识，也是它的「身份证」；改名等于换一个任务 |
| **载入 / 移除** | `bootstrap` / `bootout`：把任务交给 launchd 看管 / 拿回来 |
| **启用 / 停用** | `enable` / `disable`：跨重启的「要不要自动载入」标志位；`disable` 会**阻塞**载入 |
| **立即执行** | `kickstart`：让已载入的任务现在就跑一次 |
| **KeepAlive** | 进程退出就自动拉起（可加条件，如「仅崩溃时」「成功退出时不」） |
| **RunAtLoad** | 载入时立刻运行一次 |
| **StartInterval / StartCalendarInterval** | 每 N 秒运行 / 按日历（几点几分、星期几）运行 |
| **crontab** | 传统定时任务表（`cron` 守护进程读它） |
| **cron 表达式** | 五段：`分 时 日 月 周`；`*` 表示任意值 |
| **lsof** | 「谁打开了这个端口/文件」的查询工具，端口服务页的数据来源 |
| **PID** | 进程号 |
